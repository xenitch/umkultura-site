О книге

У Русланы дар вытаскивать людей из жизненных передряг — «специалист по счастью», к которому приходят, когда всё разладилось. Вот только собственная жизнь у неё устроена куда хуже, чем у спасённых. Современная проза с лёгким привкусом чуда.
