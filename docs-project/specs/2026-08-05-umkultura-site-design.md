# Спека: сайт umkultura.ru

Дата: 2026-08-05. Статус: дизайн согласован (макеты утверждены в визуальном брейнсторминге).

## Что строим

Статический сайт «Пространство развития умственной культуры» (Кемерово) с разделом
клуба книжных клубов: каталог клубов, городская афиша будущих чтений и архив
прошедших. Технология и рабочие процессы — по образцу xenitch.ru
(SITE-REFERENCE.md из github.com/xenitch/practice-site): генератор `build.py`
(Python + Jinja2 + markdown), результат в `docs/`, публикация GitHub Pages,
git push = деплой.

## Данные афиши

Источник — Google-таблица (id `1yqYAs1A-pI7IkMz7w2l2GKv09PjGg-RzbxI2Ng-AWaA`),
колонки: «Дата обсуждения», «Книга», «Автор», «В каком клубе обсуждают»,
«Контакты клуба», «год (для определения архива)».

Поток данных при сборке:

1. `build.py` скачивает лист как CSV (`.../export?format=csv`).
2. При успехе сохраняет копию в `data/afisha.csv` (коммитится — офлайн-фолбэк
   и история изменений афиши). При недоступности Google — берёт `data/afisha.csv`
   с предупреждением в выводе; если нет и его — падает с понятной ошибкой.
3. Разбор дат. Поддерживаемые форматы поля «Дата обсуждения» (+ год из колонки):
   - `10 августа` — точный день;
   - `август` — только месяц;
   - `13.08, 15.08` / `10.08` — числовые, возможно несколько дат через запятую;
   - несколько дат → событие показывается один раз («13 и 15 августа»),
     для деления будущее/прошлое берётся последняя дата.
   Нераспознанная дата = ошибка сборки (не молча).
4. Деление: событие уходит в архив на следующий день после точной даты;
   «только месяц» — с 1-го числа следующего месяца. Граница вычисляется на
   момент сборки (сайт обновляется пересборкой, автообновления по времени нет).
5. Спецстрока «будет голосование в группе клуба» (автор пуст) → на сайте
   «Книгу выберут голосованием». Событие «только месяц» в оглавлении получает
   подпись «в течение месяца».

## Дизайн

База — референс xenitch.ru («книжная типографика»), с усилением книжности и
своей палитрой (утверждена на макетах):

- Палитра: бумага `#f7f2e6`, чернила `#26221c`, индиго `#2b3a67` (ссылки, даты),
  терракота `#a34a2e` (кикеры, месяцы, hover), золото `#b08d3f` (линейки,
  отточия, флероны), приглушённый `#6d6152`.
- Шрифты: **Old Standard TT** (заголовки, названия книг, навигация, малые
  прописные) + **Literata** (текст). Self-hosted woff2, сабсеты cyrillic+latin,
  regular/700/italic — через google-webfonts-helper, как в референсе.
- Вёрстка афиши — «оглавление книги»: строка `«Книга» Автор ..... дата`
  с золотыми отточиями (`border-bottom: dotted`), под строкой — ссылка на клуб;
  месяцы — центрированными колонтитулами малых прописных с «··» по бокам;
  флерон ❦ в конце списка. В архиве справа у отточия — клуб, годы — крупно.
- Знак-книга в шапке и на главной: временный SVG (раскрытая книга с
  терракотовым ляссе, индиго-контур). Будет заменён картинкой от Ксении:
  SVG или PNG с прозрачным фоном ≥240×180 (лучше 360×270), отображение ~56px
  высоты в шапке.
- Прочие приёмы референса сохраняются: колонка 42rem, кегль 18px/1.65,
  старостильные цифры, `hyphens: auto`, никаких теней и анимаций.

## Генератор: отличия от референса

- `SITE` — название «Пространство развития умственной культуры», домен
  umkultura.ru, автор Ксения Костюченко.
- Раздел `bookclubs/` вместо `research/`; признак «статьи» с датой не нужен —
  автосписка статей нет. Вместо него: загрузка/разбор афиши (модуль `afisha.py`
  рядом с build.py, чтобы build.py остался маленьким) и передача в шаблоны
  `schedule.html` / `archive.html` списков событий, сгруппированных
  по месяцам/годам.
- Шаблоны: `base.html` (шапка со знаком-SVG и навигацией, подвал), `home.html`
  (заглушка без шапки), `page.html` (каталог клубов), `schedule.html`,
  `archive.html`.
- `docs/CNAME` = umkultura.ru, генерируется сборкой; `.nojekyll` тоже.

## Тесты (pytest)

- Разбор каждого формата даты, включая «несколько дат» и нераспознанное → ошибка.
- Деление будущее/прошлое относительно заданного «сегодня» (граничные дни:
  день события, следующий день, 1-е число следующего месяца).
- Спецстроки-голосования.
- Фолбэк на `data/afisha.csv` при недоступной сети (мок).
- Полный прогон сборки: все четыре страницы на месте, CNAME, .nojekyll, static.

## Вне скоупа этой итерации

- Печатная версия афиши (отдельная задача; сайт ей не мешает — источник общий).
- Описания всех семи клубов (страница стартует с теми, что есть; тексты
  соберутся с координаторов постепенно).
- Финальная картинка знака-книги (ждём от Ксении, есть времянка).
- Контакт объединения в подвале (добавится, когда определится).
